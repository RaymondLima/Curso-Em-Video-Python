# 🐍 Curso em Vídeo - Python 3

Este repositório contém todas as minhas resoluções de exercícios e anotações feitas durante o **Curso de Python 3** ministrado pelo Prof. Gustavo Guanabara (Curso em Vídeo). 

O objetivo deste repositório é documentar a minha evolução na lógica de programação e estruturação de algoritmos em Python, servindo como comprovação prática de mais de **160 horas de estudo e codificação**.

## 📁 Estrutura do Repositório

O curso é dividido em "Mundos", e estruturei os meus códigos da seguinte forma:

* **Mundo 01:** Fundamentos básicos, variáveis, tipos de dados, operadores e manipulação de strings.
* **Mundo 02:** Estruturas de controle e repetição (if, elif, for, while).
* **Mundo 03:** Estruturas de dados compostas (Tuplas, Listas, Dicionários), Funções e Modularização.
* **POO:** Aplicação de Programação Orientada a Objetos em Python (em andamento).

## 🛠️ Tecnologias Utilizadas
* Python 3
* Raciocínio Lógico e Resolução de Problemas
* IDEs mobile e desktop para os testes de código
